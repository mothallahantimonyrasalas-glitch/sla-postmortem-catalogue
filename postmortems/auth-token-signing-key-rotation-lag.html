INC-402: Auth Token Signing Key Rotation Lag

Service: Identity Gateway | Impact Tier: SEV-2 | Date: Sat Oct 03 2026 00:00:00 GMT+0530 (India Standard Time)

Root Cause Summary

JWKS edge cache TTL exceeded key rollover window causing 401 rejections on mobile clients.

Mitigation Steps

  1. Purge edge CDN cache
  2. Publish dual-key JWKS manifest
  3. Lower cache-control max-age to 300s
  4. Verify token validation
