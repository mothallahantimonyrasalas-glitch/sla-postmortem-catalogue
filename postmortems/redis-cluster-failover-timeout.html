Service: Checkout Cache | Impact Tier: SEV-1 | Date: Thu Oct 01 2026 00:00:00 GMT+0530 (India Standard Time)

Root Cause Summary

Primary Redis node hit memory ceiling during flash sale causing split-brain election timeout.

Mitigation Steps

  1. Drain stale connections
  2. Promote replica node
